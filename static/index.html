Mentions Légales & Confidentialité

1. Éditeur de l'application

MEL-IA 2.0 est une application d'intelligence artificielle conversationnelle développée sous haute exigence de confidentialité et de performance.

2. Principe de Non-Persistance en Mode Invité

Les visiteurs non connectés bénéficient d'un anonymat intégral : aucune donnée, aucun message et aucun fichier n'est conservé dans la base de données. Les données de session sont volatiles et purgées à chaque fermeture de fenêtre.

3. Comptes Utilisateurs & Données Personnelles (RGPD)

Pour les utilisateurs titulaires d'un compte, les données nécessaires à l'authentification sont stockées de façon sécurisée avec hachage cryptographique. Les utilisateurs disposent d'un droit permanent d'accès, de rectification et d'effacement intégral de leur compte et mémoires associées.

4. Propriété Intellectuelle & Documents Générés

Tous les documents (Word, PowerPoint, PDF, code) générés par l'utilisateur via MEL-IA sont la propriété exclusive de leur auteur.
