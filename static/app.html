Connexion avec Google

Pour activer la connexion avec de vrais comptes Google via Google Cloud OAuth :

  1. Ouvrez la Console Google Cloud (section API & Services > Identifiants).
  2. Créez un ID Client OAuth 2.0 pour Application Web.
  3. Renseignez la variable GOOGLE_CLIENT_ID dans votre fichier .env.
